# НАЧАТЬ ЗДЕСЬ — USOVIK / ANTIGRAVITY

Это готовый проект, а не техническое задание на создание с нуля. Распакуйте весь архив в отдельную папку и откройте эту папку как проект в Antigravity. `package.json` должен находиться в корне открытой папки.

## Готовый запрос для Antigravity

> Открой START_HERE_ANTIGRAVITY.md. Запусти существующий сайт из этого проекта, сохранив готовый дизайн, все фотографии, тексты, музыку и мини-игру. Используй Node.js 24 LTS и npm. Выполни npm ci, затем npm run check. Исправляй только обнаруженные ошибки. После успешной проверки запусти npm run dev и покажи локальное превью. Не создавай новый проект, не заменяй зависимости и не переписывай сайт с нуля. Для публикации используй папку dist, созданную npm run build.

## Версия среды

- Рекомендуется Node.js 24 LTS; файл `.nvmrc` содержит `24`.
- Минимум для приложенных тестов: Node.js 22.18.0.
- Менеджер: npm. Использовать `package-lock.json`, не удалять его.
- Установка зависимостей требует подключения к интернету. Сам сайт после загрузки не требует внешних шрифтов, изображений, API, ключей или сервера базы данных.

## Порядок запуска

В терминале из папки с `package.json`, по одной команде:

```sh
node --version
npm ci
npm run check
npm run dev
```

`npm run check` выполняет пять тестов механики игры, проверку TypeScript и производственную сборку. Локальный адрес dev-сервера указан в терминале; по умолчанию http://localhost:5173/. Если порт занят, используйте адрес, который вывел Vite.

Для просмотра производственной сборки:

```sh
npm run build
npm run preview
```

Не запускайте index.html двойным щелчком: React/Vite нужен HTTP-сервер. Не загружайте ZIP как единственный файл на хостинг — распакуйте и публикуйте содержимое `dist/`.

## Что находится в архиве

- `src/` — только используемые исходники текущей версии. Старые квесты и неиспользуемые развороты исключены.
- `public/` — портреты, иллюстрации, локальные шрифты, музыка.
- `dist/` — готовая производственная сборка. Можно разместить на статическом хостинге без дополнительной сборки.
- `tests/` — проверки завершения раунда, попаданий, промахов, паузы, количества целей и перезапуска.
- `package.json`, `package-lock.json`, `vite.config.ts`, `tsconfig*.json` — конфигурация.
- `CHECKED.md` — результаты выполненных проверок.

В архив не включены node_modules, .git, учётные данные и привязка к прежнему хостингу.

## Что сохранить при дальнейших правках

Сайт-поздравление из шести страниц, стилистика премиального мужского журнала: исходная обложка USOVIK, чёрный, тёплое золото, крупная Cormorant Garamond и Manrope. Портреты директора не перерисовывать. Поздравления оформлены как письма на светлой бумаге. Все активные страницы находятся в `src/App.tsx`; тексты — `src/editorial.ts`; основные стили — `src/styles/quest.css`.

## Мини-игра «Утиная охота»

Игра находится на странице «Выдержка», под статьёй об охоте. Кнопка «Испытать меткость» вверху страницы прокручивает к игре.

- Телефон и планшет: касание летящей утки.
- Компьютер: нажатие мышью на летящую утку.
- Клавиатура: сфокусировать игровое поле клавишей Tab; стрелки перемещают прицел, пробел стреляет, Escape ставит игру на паузу. Утки также доступны как кнопки через Tab и Enter/пробел.
- Один раунд — 30 секунд активной игры, попадание — 10 очков.
- Попадания, промахи и точность учитываются в итогах; рекорд сохраняется локально в браузере этого устройства, если localStorage доступен. Синхронизации между устройствами нет.
- При переключении вкладки или потере фокуса игра ставится на паузу. Есть ручная пауза, продолжение и новый раунд.
- Горизонтальные движения внутри игрового блока не переключают страницы журнала. Вертикальная прокрутка сохраняется.
- Область попадания увеличена: минимум 68×68 CSS-пикселей на узком экране. Интерфейс адаптируется к ширине и повороту устройства; полноэкранный режим не требуется.
- Музыка включается отдельно в шапке сайта. Игра не добавляет неожиданных звуков.
- Собственная пиксельная графика в SVG/CSS; нет зависимости от эмуляторов, Flash или оригинальных игровых файлов Nintendo.

Механика: `src/utils/duckGame.ts`. Интерфейс: `src/components/DuckHunt.tsx`. Стили: `src/components/duck-hunt.css`.

## Если возникла ошибка запуска

1. Проверьте `node --version` и выберите Node.js 24.
2. Проверьте, что терминал открыт в папке с package.json.
3. Выполните npm ci. Не смешивайте npm, yarn и pnpm.
4. После установки выполните npm run check и прочитайте первую ошибку.
5. Если не загружаются картинки, проверьте, что папки public/assets и public/fonts не потеряны при распаковке.
6. На хостинге публикуйте только содержимое dist; в конфигурации Vite уже установлен base: './' для относительных путей.
