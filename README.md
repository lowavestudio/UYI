# USOVIK — Special Edition + Duck Hunt

Начните с [START_HERE_ANTIGRAVITY.md](START_HERE_ANTIGRAVITY.md).

Node.js 24. Команды: `npm ci`, `npm run check`, `npm run dev`.
Готовая статическая сборка находится в `dist/`.

Шесть журнальных страниц и мини-игра с утками на странице «Выдержка». Управление касанием, мышью и клавиатурой; ручная и автоматическая пауза; локальный рекорд.

Фотографии директора и обложка взяты из исходного проекта. Изображения арены и леса созданы встроенным Imagegen как атмосферные иллюстрации, не документальные фотографии директора. Исходные биографические тексты сохранены.
